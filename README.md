# 🎮 Pixel Adventure – 2D Jump & Run

Willkommen bei **Pixel Adventure**! 🌙

Ein kleines, cooles 2D-Jump-&-Run-Spiel, das mit **Python, Streamlit, HTML5 Canvas, JavaScript und CSS** erstellt wurde.

## 🕹️ Gameplay

Du steuerst einen kleinen Helden durch eine nächtliche Pixelwelt.

### Steuerung

| Taste | Funktion |
|---|---|
| `A` | Nach links laufen |
| `D` | Nach rechts laufen |
| `W` | Springen |
| `Leertaste` | Springen |

## ⭐ Features

- 🎮 WASD-Steuerung
- 🏃 2D Jump & Run
- 🌄 Animierter Hintergrund
- 🌙 Mond und Sterne
- 🏔️ Parallax-Berge
- 🪙 Münzen zum Sammeln
- 👾 Gegner
- ❤️ 3 Leben
- 💥 Gegner können durch Draufspringen besiegt werden
- 📷 Kamera folgt dem Spieler
- 🏁 Ziel am Ende des Levels
- 💀 Game-Over-Bildschirm
- 🏆 Gewinn-Bildschirm
- 🔄 Neustart-Funktion
